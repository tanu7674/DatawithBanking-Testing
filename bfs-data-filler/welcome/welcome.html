BFS Test Data Filler is installed

Fill banking and financial-services forms with synthetic test data: checksum-valid card numbers, IBANs, routing numbers, SSNs, PAN, Aadhaar, IFSC and more, plus boundary and invalid values that say which rule they break.

How to use it

  1. Open the form you are testing and click the extension icon (or press Alt+Shift+B). The side panel opens.
  2. Pick a region (US, India, UK/EU) and a profile: Valid, Boundary or Invalid.
  3. Click Fill page. Each field is highlighted in its profile colour and listed in the panel with the value and why it was chosen.
  4. Change one field to Invalid in the panel to run a single negative test while the rest stay valid.
  5. Copy the data as JSON or Markdown for your test evidence or bug report. The seed reproduces the same data later.

Shortcuts

  • Alt+Shift+F fills the current page with valid data, on any site.
  • Right-click a page → BFS Test Data Filler for valid, boundary or invalid fills.

Privacy

Everything runs in your browser. The extension makes no network requests, collects nothing and only reads pages when you ask it to fill them. It works on localhost out of the box; other sites need a click on the icon (one-time access) or your permission.

The data is synthetic. Format-valid SSNs, Aadhaar or account numbers can still coincide with real ones by chance, so use it only in test environments.
